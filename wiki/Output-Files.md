# Output Files Specification

This page documents all output files generated by SANDAG PopulationSim, their formats, and how to use them.

## Output Directory Structure

```
output/
└── 2022/
    ├── synthetic_households_2022.csv    # Final households for 2022
    ├── synthetic_persons_2022.csv       # Final persons for 2022
    ├── synthetic_households.csv         # Households (non-year-specific)
    ├── synthetic_persons.csv            # Persons (non-year-specific)
    ├── synthetic_households_gq.csv      # Group quarters households
    ├── synthetic_persons_gq.csv         # Group quarters persons
    ├── mgra15_based_input_2022.csv      # MGRA-level summary for ABM
    ├── summary_region_1.csv             # Regional control totals
    ├── summary_mgra_PUMA.csv            # PUMA-level control totals
    ├── summary_mgra.csv                 # MGRA-level control totals
    ├── mgra_controls.csv                # Control definitions
    ├── region_controls.csv              # Regional control definitions
    ├── final_summary_mgra_gq.csv        # GQ summary by MGRA
    └── timing_log.csv                   # Performance timing data
```

## File Types Overview

| File Type | Purpose | Primary User | Format |
|-----------|---------|--------------|--------|
| `synthetic_*_2022.csv` | Year-specific synthesis output | ABM team | CSV, detailed attributes |
| `synthetic_*_gq.csv` | Group quarters population | ABM team | CSV, GQ-specific |
| `mgra15_based_input_*.csv` | MGRA-level summary for ABM | ABM team | CSV, zonal data |
| `summary_*.csv` | Validation control totals | Technical staff | CSV, control vs result |
| `*_controls.csv` | Control definitions | QA validation | CSV, metadata |
| `timing_log.csv` | Performance metrics | Technical staff | CSV, timing data |

## 7. Data Quality Checks

### Essential Validations

**1. File Existence:**
```powershell
# Verify all expected files exist
Test-Path output/2022/synthetic_households_2022.csv
Test-Path output/2022/synthetic_persons_2022.csv
Test-Path output/2022/synthetic_households_gq.csv
Test-Path output/2022/synthetic_persons_gq.csv
Test-Path output/2022/mgra15_based_input_2022.csv
Test-Path output/2022/summary_region_1.csv
```

**2. Row Counts:**
```python
import pandas as pd

# Households should match control total
hh = pd.read_csv('output/2022/synthetic_households_2022.csv')
print(f"Households: {len(hh):,}")  # Should be ~1,276,883

# Persons should be 2.5-3x households
persons = pd.read_csv('output/2022/synthetic_persons_2022.csv')
print(f"Persons: {len(persons):,}")  # Should be ~3,283,519
print(f"Average HH size: {len(persons) / len(hh):.2f}")  # Should be ~2.5-2.7

# GQ counts
hh_gq = pd.read_csv('output/2022/synthetic_households_gq.csv')
persons_gq = pd.read_csv('output/2022/synthetic_persons_gq.csv')
print(f"GQ households: {len(hh_gq):,}")  # Should match GQ persons
print(f"GQ persons: {len(persons_gq):,}")  # Should be ~116,411
assert len(hh_gq) == len(persons_gq), "GQ household/person count mismatch!"
```

**3. Household-Person Linkage:**
```python
# All persons should link to valid households
hh_ids = set(hh['household_id'])
person_hh_ids = set(persons['household_id'])
orphans = person_hh_ids - hh_ids
assert len(orphans) == 0, f"Found {len(orphans)} orphan persons!"

# Check GQ separately
hh_gq_ids = set(hh_gq['household_id'])
person_gq_hh_ids = set(persons_gq['household_id'])
orphans_gq = person_gq_hh_ids - hh_gq_ids
assert len(orphans_gq) == 0, f"Found {len(orphans_gq)} orphan GQ persons!"
```

**4. Geographic Coverage:**
```python
# All MGRAs should have at least some presence (households or GQ)
mgra_hh = set(hh['mgra'])
mgra_gq = set(hh_gq['mgra']) if len(hh_gq) > 0 else set()
mgra_coverage = mgra_hh | mgra_gq

# Load MGRA list
mgra_input = pd.read_csv('output/2022/mgra15_based_input_2022.csv')
total_mgras = len(mgra_input)

print(f"MGRAs with households: {len(mgra_hh)}")
print(f"MGRAs with GQ only: {len(mgra_gq - mgra_hh)}")
print(f"Total MGRAs covered: {len(mgra_coverage)} / {total_mgras}")
print(f"Empty MGRAs: {total_mgras - len(mgra_coverage)}")
```

**5. Control Total Validation:**
```python
# Check regional totals from summary file
summary_region = pd.read_csv('output/2022/summary_region_1.csv')

# Total households should match exactly
total_hh_row = summary_region[summary_region['control_name'] == 'Total_HH']
control = total_hh_row['control_value'].iloc[0]
result = total_hh_row['mgra_integer_weight'].iloc[0]
diff = result - control
pct_diff = (diff / control) * 100

print(f"Total_HH control: {control:,.0f}")
print(f"Total_HH result: {result:,.0f}")
print(f"Difference: {diff:,.0f} ({pct_diff:.3f}%)")
assert abs(pct_diff) < 0.01, f"Total HH off by {pct_diff:.3f}%!"
```

**6. NULL Value Check:**
```python
# Critical columns should have no NULLs
critical_cols_hh = ['household_id', 'mgra', 'NP', 'HHADJINC', 'workers']
critical_cols_person = ['household_id', 'mgra', 'AGEP', 'SEX']

print("Household NULLs:")
print(hh[critical_cols_hh].isnull().sum())

print("\nPerson NULLs:")
print(persons[critical_cols_person].isnull().sum())
```

## 8. Using Output Files

### Loading in Python

```python
import pandas as pd

# Read main synthesis outputs
hh = pd.read_csv('output/2022/synthetic_households_2022.csv')
persons = pd.read_csv('output/2022/synthetic_persons_2022.csv')

# Read GQ outputs
hh_gq = pd.read_csv('output/2022/synthetic_households_gq.csv')
persons_gq = pd.read_csv('output/2022/synthetic_persons_gq.csv')

# Read MGRA summary
mgra_summary = pd.read_csv('output/2022/mgra15_based_input_2022.csv')

# Basic statistics
print(f"Total households: {len(hh):,}")
print(f"Total persons: {len(persons):,}")
print(f"GQ households: {len(hh_gq):,}")
print(f"GQ persons: {len(persons_gq):,}")
print(f"Average household size: {len(persons) / len(hh):.2f}")
print(f"Average income: ${hh['HHADJINC'].mean():,.0f}")

# Merge households and persons
hh_persons = persons.merge(hh, on='household_id', suffixes=('_person', '_hh'))
print(f"Merged records: {len(hh_persons):,}")
```
